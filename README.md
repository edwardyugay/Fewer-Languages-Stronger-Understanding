# Fewer Languages, Stronger Understanding — Horizontal Video Website

## What changed
- All videos are expected to be horizontal 16:9.
- Videos are shown with `object-fit: contain`, so they are not cropped.
- The intro video is not used as a background and does not overlap with text or buttons.
- Only one active video plays at a time.
- All files are in the root folder for easy GitHub Pages upload.

## How to use on GitHub Pages
Upload all files from this folder directly into the root of your repository:
- `index.html`
- `style.css`
- `script.js`
- all `.mp4` files

Then go to Settings → Pages → Deploy from branch → main → /root.

## Replace videos
